# actuator-releases

Hapii Actuator（`qte` CLI + `qte-desktop` 桌面客户端）的**发布产物镜像**——客户真正的下载源。

- 安装：`curl -fsSL https://get.hapii.vip/install.sh | sh`（Windows：`irm https://get.hapii.vip/install.ps1 | iex`）
- 最新版资产：[releases/latest](https://github.com/hapii-x/actuator-releases/releases/latest)
- 版本清单：`releases/latest/download/manifest.json`

本仓库**只承载构建产物**（二进制 + SHA256 + manifest + 发行说明），不含任何源码；
源码与流水线在私有仓库中。安装即表示接受 EULA。
